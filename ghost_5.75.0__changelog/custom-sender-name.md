


Custom sender names for newsletters






































In the latest release, we've added the ability to set a custom sender name for your email newsletters. Your sender name can now be set from the newsletter settings page in Ghost Admin.

![](https://ghost.org/changelog/content/images/2022/04/sender-name-in-ghost.png)

This gives you full control of the sender name that appears in your subscribers inboxes, to help improve open rates and add a personal touch to your newsletter. Learn more about sender name best practices in this resource:
