


Ghost 0.5.1







































Ghost 0.5 was a landmark release, with large parts of the software almost entirely re-written. Inevitably with such a large release, we left a few bugs in. [Ghost 0.5.1](https://github.com/TryGhost/Ghost/releases/tag/0.5.1?ref=ghost.org) contains fixes for those bugs that interfered with your ability to use Ghost's features.

Here's what's new:

* **[Fixed]** Casper not working in IE
* **[Fixed]** Cannot delete users on MySQL
* **[Fixed]** Lost work if logged out while editing
* **[Fixed]** Possible to downgrade Owner user
* **[Fixed]** If author changes post author they lose access to post
* **[Fixed]** Weird status code when authorising
* **[Fixed]** Errors when uppercase used in /ghost/ URL
* **[Fixed]** UUID validation error when importing
* **[Fixed]** No notification for errors when sending mail

You can see the full [changelog](https://gist.github.com/ErisDS/45ab77c43b25395ccc85?ref=ghost.org) for more details.

How to Upgrade
--------------

All Ghost(Pro) users have been **automatically updated** and are already running Ghost 0.5.1. You're welcome :)

For people running Ghost on their own servers, you can [download Ghost 0.5.1](https://ghost.org/docs/install/?ref=ghost.org) and then check out the [upgrade documentation](https://ghost.org/docs/update/?ref=ghost.org) over on our [support site](https://ghost.org/help/?ref=ghost.org).

Enjoy!
