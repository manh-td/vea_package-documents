


Grammarly support







































The Ghost editor now has official support for Grammarly. All you need to do is install the Grammarly extension for your preferred [browser](https://support.grammarly.com/hc/en-us/articles/115000091552-Install-the-Grammarly-browser-extension?ref=ghost.org) and you can start using the AI powered writing assistant inside Ghost, to improve your writing as you type.
