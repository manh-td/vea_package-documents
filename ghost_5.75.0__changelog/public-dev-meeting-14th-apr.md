


Public Dev Meeting 14th Apr











































Today we made our slack team [available publicly](https://ghost.org/changelog/ghost-slack/) and held our meeting in the #ghost channel on slack for the first time. It was awesome to see so many people turn up and join in! Our meetings will continue to be held in slack at 5:30PM UK time every Tuesday, and if you miss it, we always write up what happens here :)

This week's major development news is the release of [Ghost 0.6.0](https://ghost.org/changelog/ghost-0-6-0/), which had changes in roughly 50% of the codebase. It's packed full of new features as well as big changes for contributors. Here's a few of the changes from last week that made it into 0.6.0:

* Code Injection no longer behind a feature flag ([#5125](https://github.com/TryGhost/Ghost/issues/5125?ref=ghost.org))
* Improved Structured Data ([#4891](https://github.com/TryGhost/Ghost/issues/4891?ref=ghost.org))
* RSS now includes post images ([#5108](https://github.com/TryGhost/Ghost/issues/5108?ref=ghost.org)) and is cached ([#5128](https://github.com/TryGhost/Ghost/pull/5128?ref=ghost.org))

In light of such extensive changes, bugs were expected (and found) and so this week we really want to push to fix as many bugs as we can. All of the open bugs can be found [here](https://github.com/TryGhost/Ghost/labels/bug?ref=ghost.org). If you'd like to help testing out the new features, looking for regressions and raising bugs if you find them is also SUPER helpful as well as bug-fixing. If you'd like to start contributing but don't know how, testing the master branch or [testing pull requests](https://ghost.org/changelog/public-dev-meeting-7th-apr/#anoteoncontributing) is a great way to get stuck in.

We are still on the look out for developers to [lead translation](https://ghost.org/docs/contributing/?ref=ghost.org) development efforts. This is happening in the #i18n channel on slack. This is not doing translations - but making translations possible by implementing the dev tools to allow people to translate. (JS skills required) - if anyone is interested, it'd be super helpful to make some progress there.

What is this?
-------------

We hold a public development meeting pretty much every Tuesday at 5:30pm London time in the #ghost channel on Ghost's [slack](https://forum.ghost.org/?ref=ghost.org). In this meeting we discuss progress, important issues, and what is and isn't on [the Roadmap](https://trello.com/b/EceUgtCL/ghost-roadmap?ref=ghost.org). It's a chance for everyone to get involved and have their say about where Ghost goes next.

Hope to see you at next week's meeting: [Tuesday 21st April, 5:30pm London time](https://everytimezone.com/?ref=ghost.org#2015-04-21,270,6bj).
