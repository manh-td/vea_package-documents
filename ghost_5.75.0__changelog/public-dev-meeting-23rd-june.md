Quick Summary
-------------

Continuation of progress on the Zelda front and general refactoring/bug fixes.

Progress Report
---------------

Non-Zelda:

* More meaningful error messages for sign in and missing email- [#5447](https://github.com/TryGhost/Ghost/pull/5447?ref=ghost.org)

Zelda:

* Updating some user permissions - [#5445](https://github.com/TryGhost/Ghost/pull/5445?ref=ghost.org), [#5451](https://github.com/TryGhost/Ghost/pull/5451?ref=ghost.org)

Priority Issues
---------------

* Looking at the tag editing component - [#3800](https://github.com/TryGhost/Ghost/issues/3800?ref=ghost.org)

Discussion
----------

* API design and using a filter paramater is something Hannah has been discussing and thinking about. She put it all together in [#5463](https://github.com/TryGhost/Ghost/issues/5463?ref=ghost.org) and would love any feedback if you have some.
* A PR was also put together as an example of how an api method method could be refactored using a pipeline ([#5467](https://github.com/TryGhost/Ghost/pull/5467?ref=ghost.org)). Any feedback on this would also be great.
* A lot of comments are also being added to the code to make sure it is well documented. The command `grunt docs` can now be run to create documentation that looks like the picture below. The plan is to have these docs hosted on `code.ghost.org` and update them with every release.

What is this?
-------------

We hold a public development meeting pretty much every Tuesday at 5:30pm London time in the #ghost channel on Ghost's [slack](https://forum.ghost.org/?ref=ghost.org). In this meeting we discuss progress, important issues, and what is and isn't on [the Roadmap](https://trello.com/b/EceUgtCL/ghost-roadmap?ref=ghost.org). It's a chance for everyone to get involved and have their say about where Ghost goes next.

Hope to see you at next week's meeting: [Tuesday 30th June, 5:30pm London time](https://everytimezone.com/?ref=ghost.org#2015-06-30,270,6bj).
