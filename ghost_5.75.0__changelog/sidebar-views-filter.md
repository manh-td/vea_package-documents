


Filter posts with sidebar views












































The default views appear under Posts which include **Drafts**, **Scheduled** and **Published** - and it's possible to create custom views using any combination of post filters and saving it with a name and colour. For example, you can create a view based on an author or a tag:

![how to add a custom side view filter in Ghost](https://ghost.org/changelog/content/images/2020/02/sidebar-views.gif)

**[Ghost(Pro)](https://ghost.org/pricing/?ref=ghost.org)** usershave access to sidebar views already. Self-hosted users can access this feature by [installing](https://ghost.org/docs/ghost-cli/?ref=ghost.org) the latest version.
