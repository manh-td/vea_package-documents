Stripe is the only natively supported payment provider with Ghost. We're aware that not everyone has access to Stripe, and we plan to add further payment providers in future.

In the meantime, it is possible to create new members via an external provider, such as PayPal or Patreon. You can also set up any third party payments system and create members in Ghost via our [API](https://ghost.org/docs/members/), or using automation tools like [Zapier](https://zapier.com/).
