### How integrations work in Ghost

There are multiple methods of integrating external tools with Ghost depending on the type of integration required:

* **Embeds —** Embed media from external tools by pasting URLs into the Ghost editor, or using HTML cards.
* **Code-injection** — Sitewide code-injection allows you to paste scripts or code from external tools to create an integration.
* **No-code tools** — Integrate with thousands of tools using [Zapier](https://zapier.com/) or [Make](https://www.make.com/en).
* **Webhooks** — Create [custom integrations](https://ghost.org/integrations/custom-integrations/) with dedicated API keys and webhooks.
* **Themes** — Some more advanced integrations call for adding some code directly into your Ghost theme files.
* **API** — For more advanced use cases, developers can build integrations using the [Content API](https://ghost.org/docs/content-api/) and [Admin API](https://ghost.org/docs/admin-api/).
