Integrate your LiveChat account with Ghost and install a chat widget on your site to connect with readers

Publishers, journalists and website creators can use [LiveChat](https://www.livechatinc.com/?utm_source=ghost&utm_campaign=integration) to speak with readers in real time, provide answers, gather feedback and grow subscribers. It takes just a few minutes to plug LiveChat into your site using using code injection. Follow this guide to find out how!

Copy the LiveChat installation code
-----------------------------------

In your LiveChat account, open the Agent App and head to Settings → Channels → [Chat widget](https://my.livechatinc.com/settings/code) and use the copy code option to grab your installation snippet.

![](/images/integrations/chat-widget-code-livechat-1_hu64406bf98384320dee236e3e7250f62a_37548_1076x0_resize_q100_h2_box_3.webp)

Install using code injection
----------------------------

Paste your installation code into the **Footer** section in the site-wide code injection feature in Ghost Admin:

![](/images/integrations/Ghost-cards_huedc570934e065d9fb5514b16c7852436_24138_1872x0_resize_q100_h2_box_3.webp)

Hit save and you’re good to go - head to your site to test your new integration is working. The LiveChat icon will appear in the bottom right hand corner of your site on every page and clicking it will open up the widget.

![](/images/integrations/Livechat-widget-ghost_hufdbb0d41d45feac4367b97c2c45e4486_147882_986x0_resize_q100_h2_box_3.webp)

Customise your LiveChat widget
------------------------------

The rest is up to you! LiveChat offer plenty of ways to customise your widget with design, branding and behaviour. Check out their handy [tutorial](https://www.livechatinc.com/kb/customize-your-chat/) on how to do this.
