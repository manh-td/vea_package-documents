Integrate actionable content analytics with your Ghost publication using a 5-minute Momently integration

[Momently](https://momently.com/?utm_source=ghost&utm_medium=integration) helps you understand your readers, discover what content is engaging and grow your audience, with an intuitive content analytics dashboard. Momently integrates directly with Ghost using simple code injection. Here’s how to get started!

Create a Momently account
-------------------------

Momently offers both free and paid plans to power your content analytics. If you haven’t already, create a new account and add your Ghost site by providing a memorable name for your site, Ghost publication URL and timezone to report in. Now you’re ready to send data from your Ghost site to Momently.

Get the tracking code
---------------------

Once you’ve created your account, you’ll be taken to the tracking code page. From here, copy the tracking code for Ghost to your clipboard:

![](https://lh4.googleusercontent.com/bhSWfoosAh7hrHoDhMGU_HnEPzn-Ij0W8Y2WBgdyPi4lMx2GSB-9LyBHaF29APVU_GQt1oDx-SySY9s0DGwlsYhuWO7rcwozwFOnP-0y7_cVcBk7_DsycdKhxXIz5r2GDAGhl3NO)

Use Ghost code injection
------------------------

In Ghost you can inject code across your entire site or on an individual post or page. Since Momently needs to track user behaviour across your entire site, we’ll use the global code injection feature which can be found in the Ghost Admin settings menu.

![](https://lh3.googleusercontent.com/flKZOEt8ZqiDtW2ys5U-MuhBekAkyDOl0pKE0J2S7AUNTjQ6iLkYwsRjiFr0iEBhWm0x01ttf2uOzFt1QBp5X5YCMaNwyAcl7a0xWjTd4AI0Ogdq5_9bpS86ojzRed8OAHqiwA3L)

Momently requires the tracking code to be in the `<head>` of each page on your site, so paste it into the Header section and hit save.

That’s it! Your site is now fully integrated with Momently and you can review your site metrics on the Momently content dashboard at any time! Here’s an example of a Momently dashboard:

![](/images/integrations/Momently-content-analytics_hu8ca5b6e1f2b31663b64f6cc90a41a350_184865_2000x0_resize_q100_h2_box.webp)
