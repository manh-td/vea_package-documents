[Analytics](/integrations/?tag=Analytics)

Want simple, privacy-focused analytics for your Ghost publication? Integrate with Plausible using straightforward code injection.

[Plausible](https://plausible.io) is a privacy-first analytics platform that delivers insights in clear and extremely simple graphs without compromising user privacy. With a few easy steps you can enable this for your Ghost site and start gaining valuable insights about your visitors right away.

Add your website to Plausible
-----------------------------

Plausible offers a free trial which you can use to get started. Follow the instructions to create your account. You will be asked to add the website you want to keep track of and select your timezone:

![](https://lh6.googleusercontent.com/l9LZOICw_464lVLD0n9V8zXOA4LDogsmc8dxg6Hd1AK-ihXowlYsLDeQsO0-_ILgdbWfDazG6aPkFZOIb2UUyDST4N2dzebcQYcoruS0lvFC_qU90WadT9e6G7bR2IfZDrgwQ-6s)

Get the tracking code
---------------------

Copy the javascript snippet from the following page and go to your Ghost Admin page:

![](https://lh4.googleusercontent.com/lUFQe3ZFem_AJ-puVg7tPu8KoEy7i6Db-_kz8aokuPEx9ZMrRSStNUcFRWjoVXDEIOCjRKjHIUJ3kWiKPRsQ0UY24sB3arKPGXFVIDNG6Bc6ASI63dJBpHT5GDa-aKL4-Ik4b7Z4)

Use Ghost code injection
------------------------

In Ghost you can inject code across your entire site or on an individual post or page. Since Plausible needs to track analytics across your entire site, we’ll use the global code injection feature which can be found in the Ghost Admin settings menu.

![](https://lh5.googleusercontent.com/pCHX0R2jaQLAj5I6mWlEJOU00s0v32KOFNu_7qeFt9S4exU-oTpexh-W8hBcJDkgP0Z6XbWvg41_Ay6W4nmXvXxbscz-Eur8B6548Gj6oK4MDDvk-3ZS14ZffsznaT5RTR5FmWlt)

Plausible requires the tracking code to be in the `<head>` of each page on your site, so paste it into the **Header** section and hit save.

All done! Your site is now fully integrated with Plausible. Login to your Plausible dashboard and start monitoring your site’s metrics!
