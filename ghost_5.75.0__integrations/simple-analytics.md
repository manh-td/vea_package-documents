[Analytics](/integrations/?tag=Analytics)

Do you want simple, clean and friendly analytics for your Ghost publication? Integrate with Simple Analytics using a straightforward code injection.

[Simple Analytics](https://simpleanalytics.io/?utm_source=ghost&utm_campaign=integration) provides businesses, marketers and developers with the site performance data they need, with easy to understand graphs, full GDPR compliance and a focus on privacy without ever tracking your users or collecting unnecessary data.

Add a website to Simple Analytics
---------------------------------

Select a [plan](https://simpleanalytics.io/#signup?utm_source=ghost&utm_campaign=integration) that is suitable for your needs and create an account. Once you’ve done this, you’ll be asked to add your site. Enter the domain for your Ghost publication:

![](/images/integrations/Add-a-website_hu68edf28d969df31eec39fe0fa9298902_40484_1462x0_resize_q100_h2_box_3.webp)

Get the tracking code
---------------------

Once you’ve added your site you’ll see a list of all the sites in your account. Navigate to Install Instructions for your site:

![](/images/integrations/Your-website-install-instructions_hu354c7465f7ab9a45e77a0ba8544f1909_26388_1670x0_resize_q100_h2_box_3.webp)

From here you’ll see your tracking code. Copy this and head to Ghost Admin:

![](/images/integrations/Tracking-code_hucd6a06928186d28a3fc3c5ee0131725b_84450_1850x0_resize_q100_h2_box_3.webp)

Use Ghost code injection
------------------------

In Ghost you can inject code across your entire site or on an individual post or page. Since Simple Analytics needs to track analytics across your entire site, we’ll use the global code injection feature which can be found in the Ghost Admin settings menu.

![](/images/integrations/code-injection-footer_hu60aa3e6a295a12ce4e040df79eb67285_140173_2000x0_resize_q100_h2_box_3.webp)

Simple Analytics requires the tracking code to be in the `<body>` of each page on your site, so paste it into the **Footer** section and hit save.

Your site is now fully integrated with Simple Analytics. Enjoy privacy-focused data for your Ghost publication. If you’d like to share public website statistics for your audience, you can do this using the [Simple Analytics embed graph](https://docs.simpleanalytics.com/embed-graph-on-your-site?utm_source=ghost&utm_campaign=integration).
