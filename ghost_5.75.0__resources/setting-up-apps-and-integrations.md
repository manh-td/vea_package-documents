




Setting up apps and integrations








































You can extend your Ghost site and connect it with hundreds of the most popular apps and tools using **integrations**.

Whether you need to automatically publish new posts on social media, connect your favorite analytics tool, or sync your community — our [integrations library](https://ghost.org/integrations/?ref=ghost.org) has you covered.

Many integrations are as simple as inserting an embed by pasting a link, or copying a snippet of code directly from an app and pasting it into Ghost. Our integration tutorials help creators of all kinds get apps and integrations up and running quickly — no technical knowledge required!

![](https://ghost.org/resources/content/images/2022/08/integrations.png)

Core integrations
-----------------

Ghost comes with a few core integrations to help you create and promote content:

* The native [Unsplash](https://ghost.org/integrations/unsplash/?ref=ghost.org) integration allows you to browse and insert beautiful imagery into any post or feature image.
* Our [Google AMP](https://ghost.org/integrations/google-amp/?ref=ghost.org) integration renders all content on your site to be available in a mobile-ready AMP format.
* Use the [FirstPromoter](https://ghost.org/integrations/firstpromoter/?ref=ghost.org) integration to set up a referral program so your biggest fans can promote your work for an incentive.

Zapier
------

Zapier is a no-code tool for building powerful automation, and you can use the official [Zapier](https://ghost.org/integrations/zapier/?ref=ghost.org) integration to connect your Ghost site to over 1,000 external services.

Custom integrations
-------------------

For more advanced automation, custom Ghost integrations with dedicated API keys can be created from the Integrations page within Ghost Admin.

![](https://static.ghost.org/v4.0.0/images/iawriter-integration.png)

No coding skills? No problem. These custom integrations allow you to use the Ghost API to create powerful workflows, such as sending content from your favorite desktop editor into Ghost as a new draft without writing any code.
