Ideas and tools 🛠️
------------------

* Rob Conery turned his Ghost site into a full-fledged course platform. Learn about the engineering behind it in "[Hacking Ghost for Fun and Profit](https://robconery.com/frontend/hacking-ghost/?ref=ghost.org)."
* Style external links distinctly (with the little arrow denoting you're leaving the site) with [this guide by CSS in Real Life](https://css-irl.info/styling-external-links-with-attribute-selectors/?ref=ghost.org).
* If you're writing CSS, you've likely used some of its many units like `px`, `rem`, and `vw`. But have you used the new line height unit? [Andy Bell breaks down everything you need to know](https://andy-bell.co.uk/lh-units-are-cool/?ref=ghost.org) about `lh`.
* [BrandGuide is a repository of company design identities](https://brandguide.page/?ref=ghost.org), that is, the company's guides to logos, typefaces, color, and everything else that makes them what they are.
