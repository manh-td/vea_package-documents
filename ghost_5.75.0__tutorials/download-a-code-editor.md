





Download a code editor









































---


Whether you're making a small tweak to your routes or a gargantuan edit to a theme, a code editor is the right tool for the job. In this tutorial, learn how to download the free code editor, Visual Studio Code.

Download VS Code
----------------

Microsoft's VS Code is an industry-leading, free code editor. It has loads of features to improve the code writing experience.

[Download the version for your OS](https://code.visualstudio.com/Download?ref=ghost.org).

![The VS Code download page](https://ghost.org/tutorials/content/images/2022/05/download-vs-code.png)

Open the downloaded file and follow the instructions to install the code editor on your system.

For an overview of the program, check out VS Code's *Getting Started* video.

Summary
-------

With VS Code downloaded on your machine, you're now equipped to edit files and [customize a theme](https://ghost.org/tutorials/open-a-theme-in-a-code-editor/) 🛠️

We're excited to see what you get up to, so be sure to let us know in the [Ghost Forum](https://forum.ghost.org/?ref=ghost.org). It's a great place to learn from the community and see what we're up to.
